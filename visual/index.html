goroutine 拓扑

main× 1装配依赖 · 启动 · 优雅关闭
Scheduler× 1从队列取任务，同项目串行化，防并发部署打架
Worker Pool× Nsemaphore 限流，每个构建一个 goroutine
BuilderDocker 容器隔离执行，ctx 超时取消
Log Reader读容器 stdout/stderr → LogPipe
Log Writer批量落库，慢订阅者丢弃
Diagnoser失败时异步调 LLM，不阻塞状态流转
HTTP Server× Mnet/http 每请求一个 goroutine
SSE handler订阅 LogPipe 写入响应，慢客户端丢弃
Reconciler× 1周期恢复孤儿任务 · 超时清理
signal handler× 1SIGTERM → 停止取新任务 → wg.Wait() 宽限期
